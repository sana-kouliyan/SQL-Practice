# SQL Exercises
**Practice of SQL Queries and Database Manipulation**

## Overview
This repository contains SQL exercises to strengthen practical SQL skills for data analysis. Exercises cover basic to advanced queries, including joins, aggregations, filtering, grouping, and subqueries.

## Repository Structure
- `Basic_queries` → Simple SELECT, WHERE, ORDER BY, JOIN
- `Advances_queries` → JOIN, GROUP BY, aggregates, Advanced filtering, HAVING clauses, Nested queries and subqueries

## Skills Practiced
- Writing SELECT statements  
- Filtering and sorting data  
- Joining tables and aggregating data  
- Using GROUP BY and HAVING  
- Writing subqueries
